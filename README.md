# Datum submissions

Additions and corrections for [Datum](https://datum-gis.com), a directory of
public government ArcGIS REST endpoints in the United States.

### Add a server
[Open a submission](../../issues/new?template=add-server.yml) for a public
ArcGIS REST endpoint that is not listed.

### Report a problem
[Open a request](../../issues/new?template=update-server.yml) when a URL has
moved, a server is gone, or a record is filed wrongly.

The forms on the site prefill either one for you.

---

Submit the top level `.../rest/services` endpoint, not an individual layer.
US government and public interest servers only.
